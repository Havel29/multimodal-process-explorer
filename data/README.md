# data/

You don't need this folder to try the explorer: the open example is in
`examples/xray-pathways/`, and the setup page uploads files from wherever you
keep them.

The folder is for files that must stay on your computer, such as event logs and
images under a data-use agreement (for example CDSL). Everything in it except
this file is ignored by Git, so nothing placed here is committed by accident.
